# Microsoft Build 2026

## La conferencia anual de desarrolladores de Microsoft

**Microsoft Build 2026** se realizará los días **2 y 3 de junio de 2026** en **San Francisco (EE.UU.)** y de forma **online global**. Es el evento anual más importante para desarrolladores organizado por Microsoft, con un foco fuerte en **IA, agentes, Azure, GitHub, .NET y Windows**.

El keynote principal estará a cargo de **Satya Nadella**, CEO de Microsoft, transmitido en vivo desde San Francisco.

Registro e información oficial: [build.microsoft.com](https://build.microsoft.com/).

## Participación desde FIUNA

El Club de Programación FIUNA acompaña el evento con actividades comunitarias para estudiantes:

- **Viewing party** del keynote principal y sesiones seleccionadas.
- **Revisión comunitaria** de los anuncios más relevantes para estudiantes.
- **Workshops de seguimiento** sobre las tecnologías presentadas (Azure AI, GitHub Copilot, .NET, agentes).

Las fechas y ubicación de las actividades locales serán anunciadas en los canales del club conforme se publiquen los detalles oficiales de Build 2026.

## Temas principales de Build 2026

- **Agentes y apps nativas de IA** (Agents & AI-native Apps).
- **Modelos y entrenamiento** (Model Infrastructure & Applied Science).
- **Herramientas y frameworks de desarrollo** (Copilot, Visual Studio, VS Code, GitHub).
- **Cloud platform y data** (Azure, datos, observabilidad).
- **IA responsable**.
- **Windows** y desarrollo para la plataforma.

## Recursos para estudiantes

- [Microsoft Learn](https://learn.microsoft.com/): rutas de aprendizaje gratuitas.
- [GitHub Student Developer Pack](https://education.github.com/pack): recursos gratuitos para estudiantes.
- **Azure for Students**: créditos iniciales sin tarjeta de crédito.
- **Certificaciones Microsoft**: descuentos para estudiantes.

- Entusiastas de las tecnologías Microsoft.
